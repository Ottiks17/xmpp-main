# Контракт сообщений v1.0 (сервер мессенджера)

Нормативное описание. Расширяет `stage1_contract.md` (приоритеты, статусы, `message_id`) и
реализует ТЗ-1, ТЗ-6…10. Все пути доступны с префиксом `/v1` (`/v1/send_message` и т. д.)
и без него.

## 1. Модель сообщения

| Поле | Тип | Правило |
|---|---|---|
| `message_id` | UUID4 | присваивает сервер, сквозной (БД сервера = Room на ТСД) |
| `external_id` | строка ≤ 64 | необязательно; ключ идемпотентности от внешней системы |
| `to` | JID или логин | также принимаются `recipient`, `user`, `username`, `jid`, `send_to`, `target` |
| `type` | `text` / `task` / `command` | по умолчанию `text` |
| `priority` | `low` / `normal` / `high` / `critical` | по умолчанию `normal` |
| `message` | строка ≤ 256 символов | также `msg`, `text`, `body`, `content`; для `task`/`command` можно опустить — сервер подставит читаемый текст |
| `payload` | объект | обязателен для `task` и `command`, запрещён для `text` |

### payload для `type=task` (ТЗ-7…10)

| Поле | Обязательно | Правило |
|---|---|---|
| `kind` | да | `pick_store` (наборка в магазине), `receive` (приёмка), `pick_wh` (наборка на складе), `inventory` (ревизия) |
| `task_id` | да | строка ≤ 64 |
| `subtype` | нет | только для `inventory`: латиница/цифры/`_`/`-`, ≤ 32 |
| `params` | нет | до 10 пар «имя — значение»; имя `[A-Za-z0-9_]{1,32}`, значение строка ≤ 64 |

Имена параметров (`store`, `doc`, `zone` и т. п.) **предложены** и должны быть подтверждены командой WMS.

### payload для `type=command`

`name`: `ping`, `restart`, `update`, `notification`. Для `update` и `notification` обязателен
`arg` (≤ 128), для остальных запрещён.

### XMPP

```xml
<message to="user@domain" type="chat" id="6f1c…">
  <body>Наборка в магазине № 12345</body>
  <request xmlns="urn:xmpp:receipts"/>
  <markable xmlns="urn:xmpp:chat-markers:0"/>
  <priority xmlns="urn:wakeup:msg:0" level="high"/>
  <task xmlns="urn:wakeup:msg:0" kind="pick_store" id="12345">
    <param name="store" value="17"/>
  </task>
</message>
```

Для `command`: `<command xmlns="urn:wakeup:msg:0" name="update" arg="1.26.80"/>`.
Клиенты без поддержки нового элемента показывают `<body>` как обычный текст.

## 2. Отправка

`POST /send_message` (путь настраивается `rest_api.endpoint`):

```json
{"to": "user@arsenal", "type": "task", "priority": "high", "external_id": "ORD-7781",
 "payload": {"kind": "pick_store", "task_id": "12345", "params": {"store": "17"}}}
```

Ответ `200`: `status`, `message_id`, `priority`, `message_status` (`queued`), `type`, `to`, `message`,
`external_id` и `payload` (если были), `send_time`.

**Идемпотентность.** Повторный запрос с тем же `external_id` не отправляет сообщение заново:
ответ `200` с тем же `message_id` и `"duplicate": true`.

Если текста нет (и это `type=text`) — `400`. Прежнее поведение (тело запроса как текст) включается
только настройкой `rest_api.legacy_payload_as_message`.

`POST /broadcast`: `recipients` (список строк, не больше `broadcast_max_recipients`, по умолчанию 200),
остальные поля как выше. `external_id` рассылки действует отдельно для каждого получателя.
Ответ: `total`, `success`, `failed`, `duplicates`, `results[]`.

## 3. Статус

- `GET /messages/{message_id}` — `message_id`, `recipient`, `priority`, `status`, `send_time`,
  `delivery_time`, `read_time`.
- `POST /messages/status` — `{"ids": ["…", …]}` (до 100) → `messages[]` и `not_found[]`.
- `GET /get_messages` — список с фильтрами `limit`, `type`, `status`, `priority`.

Статусы: `queued → sent → delivered → read`, ветка `failed`. Назад статус не откатывается.
Передача наружу — pull (опрос). Push (webhook/Kafka) не реализован.

## 4. Ошибки

```json
{"error": {"code": "bad_request", "message": "…"}, "message_id": "…"}
```

Коды: `bad_request` (400), `unauthorized` (401), `admin_disabled` (403), `not_found` (404),
`method_not_allowed` (405), `rate_limited` (429), `internal` (500). Поля вроде `message_id`
передаются рядом с `error`.

## 5. Авторизация и лимиты

- Ключ — заголовок `X-API-Key` (если `rest_api.api_key` задан). Передача в `?api_key=` включается
  `rest_api.allow_api_key_query`.
- Лимит: 100 запросов в минуту на IP для отправки, рассылки, пакетного статуса и эндпоинтов терминалов.

## 6. Эндпоинты для ТСД

| Запрос | Ответ |
|---|---|
| `GET /v1/auth/xmpp?deviceId=…` | `xmppHost`, `xmppPort`, `xmppLogin`, `xmppPassword`, `apiHost`, `apiPort` |
| `POST /v1/wakeup/confirm?deviceId=…&taskId=…` | `{"status": "ok"}` |
| `GET /v1/config/trusted-senders?deviceId=…` | `{"senders": ["server@domain", …]}` |

Учётные данные выдаются только зарегистрированному активному терминалу, у которого к реестру привязана
учётная запись; иначе `404`. Если у терминала задан токен, нужен заголовок `X-Device-Token` (`401` при
несовпадении). `xmppHost`/`xmppPort` берутся из `xmpp.server`/`xmpp.port`; `apiHost`/`apiPort` — из
`rest_api.public_host`/`public_port` (если пусто — хост запроса и `rest_api.port`).
Список `senders` задаётся `rest_api.trusted_senders`.

### Административный API реестра (нужен `api_key`, иначе `403`)

- `GET /v1/admin/devices`, `GET /v1/admin/devices/{deviceId}`
- `PUT /v1/admin/devices/{deviceId}` — `xmpp_login`, `xmpp_password`, `active`, `token`, `generate_token`.
  `xmpp_login: ""` отвязывает учётную запись. Сгенерированный токен показывается один раз.
- `DELETE /v1/admin/devices/{deviceId}`

Пароли хранятся зашифрованными (Fernet). Ключ — переменная `DEVICE_REGISTRY_KEY`, иначе файл
`device_registry.key` рядом с БД (не коммитить, держать на томе).

## 7. Настройки (`rest_api`)

| Ключ | По умолчанию | Назначение |
|---|---|---|
| `allow_api_key_query` | `false` | принимать `?api_key=` |
| `legacy_payload_as_message` | `false` | старое поведение при отсутствии текста |
| `broadcast_max_recipients` | `200` | размер списка рассылки |
| `trusted_senders` | `[]` | ответ `/v1/config/trusted-senders` |
| `public_host`, `public_port` | пусто, `0` | `apiHost`, `apiPort` в `/v1/auth/xmpp` |

Каждую можно переопределить переменной окружения (`REST_ALLOW_API_KEY_QUERY`,
`REST_LEGACY_PAYLOAD_AS_MESSAGE`, `REST_BROADCAST_MAX_RECIPIENTS`, `REST_TRUSTED_SENDERS` — через запятую,
`REST_PUBLIC_HOST`, `REST_PUBLIC_PORT`).

## 8. Схема БД (SQLite, миграция v3)

`messages` + `external_id` (уникален среди исходящих), `content_type`, `payload` (JSON);
таблицы `devices` и `wakeup_confirms`. Перед миграцией создаётся копия БД `<db>.bak-v<версия>`.

# Роли данных в модели списка чатов (поверх стандартных Qt.DisplayRole и т.п.)
ROLE_JID = Qt.UserRole + 1
ROLE_PREVIEW = Qt.UserRole + 2
ROLE_TIME = Qt.UserRole + 3
ROLE_UNREAD = Qt.UserRole + 4

ROW_HEIGHT = 64
AVATAR_SIZE = 48
AVATAR_MARGIN = 8

# Палитра инициалов-аватаров (детерминированная по хешу JID, как в Telegram)
_AVATAR_COLORS = [
    "#e17076", "#7bc862", "#e5ca77", "#65aadd",
    "#a695e7", "#ee7aae", "#6ec9cb", "#faa774",
]


def avatar_color(jid: str) -> QColor:
    """Стабильный цвет фона аватара по JID — один и тот же контакт всегда одного цвета."""
    idx = int(hashlib.md5(jid.encode("utf-8")).hexdigest(), 16) % len(_AVATAR_COLORS)
    return QColor(_AVATAR_COLORS[idx])


def initials(jid: str) -> str:
    """Одна-две буквы для аватара: из части до '@', либо первая буква JID."""
    local = jid.split("@", 1)[0]
    parts = [p for p in local.replace(".", " ").replace("_", " ").split(" ") if p]
    if not parts:
        return "?"
    if len(parts) == 1:
        return parts[0][:2].upper()
    return (parts[0][0] + parts[1][0]).upper()


class ChatListDelegate(QStyledItemDelegate):
    """Рисует строку списка чатов: аватар-кружок, имя, превью, время, бейдж непрочитанных."""

    def sizeHint(self, option: QStyleOptionViewItem, index: QModelIndex) -> QSize:
        return QSize(option.rect.width(), ROW_HEIGHT)

    def paint(self, painter: QPainter, option: QStyleOptionViewItem, index: QModelIndex) -> None:

        painter.save()
        painter.setRenderHint(QPainter.Antialiasing)

        rect: QRect = option.rect

        if option.state & 0x0001:  # QStyle.State_Selected
            painter.fillRect(rect, QColor(TELEGRAM_DARK["bg_selected"]))
        elif option.state & 0x0040:  # QStyle.State_MouseOver
            painter.fillRect(rect, QColor(TELEGRAM_DARK["bg_hover"]))

        jid = index.data(ROLE_JID) or ""
        name = index.data(Qt.DisplayRole) or jid
        preview = index.data(ROLE_PREVIEW) or ""
        time_text = index.data(ROLE_TIME) or ""
        unread = index.data(ROLE_UNREAD) or 0

        # --- аватар ---
        ax = rect.left() + AVATAR_MARGIN
        ay = rect.top() + (rect.height() - AVATAR_SIZE) // 2
        avatar_rect = QRect(ax, ay, AVATAR_SIZE, AVATAR_SIZE)

        path = QPainterPath()
        path.addEllipse(avatar_rect.x(), avatar_rect.y(), AVATAR_SIZE, AVATAR_SIZE)
        painter.fillPath(path, avatar_color(jid))

        painter.setPen(QColor("#ffffff"))
        avatar_font = QFont(painter.font())
        avatar_font.setPointSize(13)
        avatar_font.setBold(True)
        painter.setFont(avatar_font)
        painter.drawText(avatar_rect, Qt.AlignCenter, initials(jid))

        # --- текстовая колонка ---
        text_left = avatar_rect.right() + AVATAR_MARGIN + 4
        text_right = rect.right() - AVATAR_MARGIN
        badge_reserved = 28 if unread else 0

        name_font = QFont(painter.font())
        name_font.setPointSize(10)
        name_font.setBold(True)
        painter.setFont(name_font)
        painter.setPen(QColor(TELEGRAM_DARK["text_primary"]))
        name_rect = QRect(text_left, rect.top() + 10, text_right - text_left - 60, 20)
        fm_name = QFontMetrics(name_font)
        painter.drawText(name_rect, Qt.AlignLeft | Qt.AlignVCenter, fm_name.elidedText(name, Qt.ElideRight, name_rect.width()))

        time_font = QFont(painter.font())
        time_font.setPointSize(8)
        painter.setFont(time_font)
        painter.setPen(QColor(TELEGRAM_DARK["text_secondary"]))
        time_rect = QRect(text_right - 56, rect.top() + 10, 56, 20)
        painter.drawText(time_rect, Qt.AlignRight | Qt.AlignVCenter, time_text)

        preview_font = QFont(painter.font())
        preview_font.setPointSize(9)
        painter.setFont(preview_font)
        painter.setPen(QColor(TELEGRAM_DARK["text_secondary"]))
        preview_rect = QRect(text_left, rect.top() + 34, text_right - text_left - badge_reserved, 20)
        fm_preview = QFontMetrics(preview_font)
        painter.drawText(
            preview_rect, Qt.AlignLeft | Qt.AlignVCenter,
            fm_preview.elidedText(preview, Qt.ElideRight, preview_rect.width()),
        )

        # --- бейдж непрочитанных ---
        if unread:
            badge_d = 20
            bx = rect.right() - AVATAR_MARGIN - badge_d
            by = rect.top() + 36
            badge_rect = QRect(bx, by, badge_d, badge_d)
            badge_path = QPainterPath()
            badge_path.addEllipse(bx, by, badge_d, badge_d)
            painter.fillPath(badge_path, QColor(TELEGRAM_DARK["accent"]))
            painter.setPen(QColor("#ffffff"))
            badge_font = QFont(painter.font())
            badge_font.setPointSize(7)
            badge_font.setBold(True)
            painter.setFont(badge_font)
            text = str(unread) if unread < 100 else "99+"
            painter.drawText(badge_rect, Qt.AlignCenter, text)

        painter.restore()

        self.search_text_changed.emit(text)

ROLE_MSG = Qt.UserRole + 1

BUBBLE_MAX_WIDTH_RATIO = 0.65
BUBBLE_PAD_V = 8
BUBBLE_PAD_H = 12
BUBBLE_RADIUS = 12
GROUP_SPACING = 2       # между сообщениями одного отправителя подряд
MSG_SPACING = 8         # между сообщениями разных отправителей
TAIL_RESERVE = 46       # место под время + галочку в правом нижнем углу пузыря

_STATUS_ICON = {
    "sending": "\u23F3",      # ⏳
    "delivered": "\u2713",    # ✓
    "read": "\u2713\u2713",   # ✓✓
    "failed": "\u2717",       # ✗
}


class MessageModel(QAbstractListModel):
    """Список сообщений одного открытого диалога."""

    def __init__(self, parent=None) -> None:
        super().__init__(parent)
        self._items: list[dict] = []

    # ---- Qt.AbstractListModel API ----

    def rowCount(self, parent: QModelIndex = QModelIndex()) -> int:
        return 0 if parent.isValid() else len(self._items)

    def data(self, index: QModelIndex, role: int = Qt.DisplayRole):
        if not index.isValid() or not (0 <= index.row() < len(self._items)):
            return None
        if role in (Qt.DisplayRole, ROLE_MSG):
            return self._items[index.row()]
        return None

    # ---- наш API ----

    def set_messages(self, messages: list[dict]) -> None:
        """Полная замена содержимого (вызывается при переключении чата)."""
        self.beginResetModel()
        self._items = list(messages)
        self.endResetModel()

    def append_message(self, msg: dict) -> None:
        """Добавить одно сообщение в конец без пересборки всей модели."""
        row = len(self._items)
        self.beginInsertRows(QModelIndex(), row, row)
        self._items.append(msg)
        self.endInsertRows()

    def update_message(self, msg_id: str, **changes) -> bool:
        """Точечно обновить сообщение по msg_id (например, статус доставки)."""
        for i, m in enumerate(self._items):
            if m.get("msg_id") == msg_id:
                m.update(changes)
                idx = self.index(i, 0)
                self.dataChanged.emit(idx, idx)
                return True
        return False

    def message_at(self, row: int) -> dict | None:
        return self._items[row] if 0 <= row < len(self._items) else None

    def is_grouped_with_previous(self, row: int) -> bool:
        """True, если сообщение row — продолжение группы того же отправителя (меньший отступ)."""
        if row <= 0:
            return False
        return self._items[row]["type"] == self._items[row - 1]["type"]


class MessageDelegate(QStyledItemDelegate):
    """Рисует один пузырь сообщения через QTextLayout (без HTML)."""

    def _bubble_font(self) -> QFont:
        f = QFont()
        f.setPointSize(9)
        return f

    def _meta_font(self) -> QFont:
        f = QFont()
        f.setPointSize(8)
        return f

    def _max_bubble_width(self, option: QStyleOptionViewItem) -> int:
        return max(120, int(option.rect.width() * BUBBLE_MAX_WIDTH_RATIO))

    def _layout_text(self, text: str, font: QFont, max_width: int) -> tuple[QTextLayout, float]:
        """Раскладывает текст с переносом по словам, возвращает layout и высоту в px."""
        layout = QTextLayout(text, font)
        text_option = QTextOption()
        text_option.setWrapMode(QTextOption.WrapAtWordBoundaryOrAnywhere)
        layout.setTextOption(text_option)

        layout.beginLayout()
        height = 0.0
        while True:
            line = layout.createLine()
            if not line.isValid():
                break
            line.setLineWidth(max_width)
            line.setPosition(QRectF(0, height, max_width, 0).topLeft())
            height += line.height()
        layout.endLayout()
        return layout, height

    def sizeHint(self, option: QStyleOptionViewItem, index: QModelIndex) -> QSize:
        msg = index.data(ROLE_MSG)
        if not msg:
            return QSize(option.rect.width(), 0)

        grouped = index.model().is_grouped_with_previous(index.row())
        max_w = self._max_bubble_width(option)
        text_w = max_w - 2 * BUBBLE_PAD_H
        _, text_h = self._layout_text(msg["message"], self._bubble_font(), text_w)

        bubble_h = int(text_h) + 2 * BUBBLE_PAD_V + 14  # +14 под строку времени/галочки
        top_margin = GROUP_SPACING if grouped else MSG_SPACING
        return QSize(option.rect.width(), bubble_h + top_margin)

    def paint(self, painter: QPainter, option: QStyleOptionViewItem, index: QModelIndex) -> None:

        msg = index.data(ROLE_MSG)
        if not msg:
            return

        painter.save()
        painter.setRenderHint(QPainter.Antialiasing)

        rect = option.rect
        grouped = index.model().is_grouped_with_previous(index.row())
        top_margin = GROUP_SPACING if grouped else MSG_SPACING

        max_w = self._max_bubble_width(option)
        text_w = max_w - 2 * BUBBLE_PAD_H
        font = self._bubble_font()
        layout, text_h = self._layout_text(msg["message"], font, text_w)

        bubble_w = min(max_w, max(int(layout.maximumWidth()) + 2 * BUBBLE_PAD_H, 60))
        bubble_h = int(text_h) + 2 * BUBBLE_PAD_V + 14

        is_sent = msg["type"] == "sent"
        if is_sent:
            bx = rect.right() - bubble_w - 12
            bubble_color = QColor(TELEGRAM_DARK["bubble_sent"])
        else:
            bx = rect.left() + 12
            bubble_color = QColor(TELEGRAM_DARK["bubble_recv"])
        by = rect.top() + top_margin

        path = QPainterPath()
        path.addRoundedRect(bx, by, bubble_w, bubble_h, BUBBLE_RADIUS, BUBBLE_RADIUS)
        painter.fillPath(path, bubble_color)

        # --- текст сообщения ---
        painter.setPen(QColor(TELEGRAM_DARK["text_primary"]))
        painter.setFont(font)
        layout.draw(painter, QPointF(bx + BUBBLE_PAD_H, by + BUBBLE_PAD_V))

        # --- время (+ статус для исходящих) ---
        meta_font = self._meta_font()
        painter.setFont(meta_font)
        fm = QFontMetrics(meta_font)
        time_text = msg.get("time", "")

        if is_sent:
            status = msg.get("status", "sending")
            icon = _STATUS_ICON.get(status, "")
            icon_color = {
                "read": TELEGRAM_DARK["accent"],
                "delivered": TELEGRAM_DARK["text_secondary"],
                "failed": TELEGRAM_DARK["error"],
                "sending": TELEGRAM_DARK["text_secondary"],
            }.get(status, TELEGRAM_DARK["text_secondary"])

            meta_y = by + bubble_h - BUBBLE_PAD_V - fm.height() + fm.ascent()
            icon_w = fm.horizontalAdvance(icon)
            time_w = fm.horizontalAdvance(time_text)

            painter.setPen(QColor(TELEGRAM_DARK["text_secondary"]))
            painter.drawText(int(bx + bubble_w - BUBBLE_PAD_H - icon_w - time_w - 4), int(meta_y), time_text)
            painter.setPen(QColor(icon_color))
            painter.drawText(int(bx + bubble_w - BUBBLE_PAD_H - icon_w), int(meta_y), icon)
        else:
            meta_y = by + bubble_h - BUBBLE_PAD_V - fm.height() + fm.ascent()
            painter.setPen(QColor(TELEGRAM_DARK["text_secondary"]))
            painter.drawText(int(bx + bubble_w - BUBBLE_PAD_H - fm.horizontalAdvance(time_text)), int(meta_y), time_text)

        painter.restore()

    def refresh_contacts(self, current_user: str) -> None:
        """Пересобрать список контактов в комбобоксе (была update_contacts_list)."""
        if not os.path.exists(self.db_path):
            return
        try:
            conn = sqlite3.connect(self.db_path)
            cursor = conn.cursor()
            cursor.execute(
                """
                SELECT DISTINCT
                    CASE
                        WHEN sender = ? THEN recipient
                        WHEN recipient = ? THEN sender
                    END as contact
                FROM messages
                WHERE sender = ? OR recipient = ?
                """,
                (current_user, current_user, current_user, current_user),
            )
            contacts = set()
            for row in cursor.fetchall():
                contact = row[0]
                if contact and contact != current_user:
                    contact = contact.split("/")[0]
                    contacts.add(contact)
            conn.close()
        except Exception:
            return

        current = self.contact_combo.currentText()
        self.contact_combo.blockSignals(True)
        self.contact_combo.clear()
        self.contact_combo.addItem("Все диалоги")
        for contact in sorted(contacts):
            self.contact_combo.addItem(contact)
        idx = self.contact_combo.findText(current)
        self.contact_combo.setCurrentIndex(idx if idx >= 0 else 0)
        self.contact_combo.blockSignals(False)

    def reload(self) -> None:
        try:
            selected = self.contact_combo.currentText()
            self.table.setRowCount(0)
            self.status_label.setText("Загрузка...")

            if not os.path.exists(self.db_path):
                self.status_label.setText("\u274C База данных не найдена")
                return

            conn = sqlite3.connect(self.db_path)
            cursor = conn.cursor()
            if selected == "Все диалоги" or not selected:
                cursor.execute(
                    """
                    SELECT type, sender, recipient, message, send_time, delivery_time, log_time
                    FROM messages ORDER BY id DESC LIMIT 500
                    """
                )
            else:
                clean_contact = selected.split("/")[0]
                cursor.execute(
                    """
                    SELECT type, sender, recipient, message, send_time, delivery_time, log_time
                    FROM messages WHERE sender LIKE ? OR recipient LIKE ?
                    ORDER BY id DESC LIMIT 500
                    """,
                    (f"%{clean_contact}%", f"%{clean_contact}%"),
                )
            rows = cursor.fetchall()
            conn.close()

            self.table.setRowCount(len(rows))
            for i, row in enumerate(rows):
                msg_type, sender, recipient, message, send_time, delivery_time = row[0], row[1], row[2], row[3], row[4], row[5]
                message = message[:150] + "..." if len(message) > 150 else message
                send_time = send_time[:16] if send_time else "-"
                delivery_time = delivery_time[:16] if delivery_time else "-"

                type_color = "#43b581" if msg_type == "SENT" else "#5288c1"
                type_icon = "\U0001F4E4" if msg_type == "SENT" else "\U0001F4E5"

                type_item = QTableWidgetItem(f"{type_icon} {msg_type}")
                type_item.setForeground(QColor(type_color))

                self.table.setItem(i, 0, type_item)
                self.table.setItem(i, 1, QTableWidgetItem(sender.split("/")[0] if sender else "-"))
                self.table.setItem(i, 2, QTableWidgetItem(recipient.split("/")[0] if recipient else "-"))
                self.table.setItem(i, 3, QTableWidgetItem(message))
                self.table.setItem(i, 4, QTableWidgetItem(send_time))
                self.table.setItem(i, 5, QTableWidgetItem(delivery_time))

            self.status_label.setText(f"\U0001F4CA Загружено {len(rows)} сообщений")
        except Exception as exc:
            self.status_label.setText(f"\u274C Ошибка: {exc}")

    # ------------------------------------------------------------------ внутреннее

    def _show_context_menu(self, position) -> None:
        menu = QMenu(self)
        copy_action = menu.addAction("\U0001F4CB Копировать текст сообщения")
        copy_action.triggered.connect(self._copy_selected)
        menu.exec_(self.table.viewport().mapToGlobal(position))

    def _copy_selected(self) -> None:
        row = self.table.currentRow()
        if row < 0:
            return
        item = self.table.item(row, 3)
        if item:
            from PyQt5.QtWidgets import QApplication
            QApplication.clipboard().setText(item.text())
            self.status_label.setText("\u2705 Скопировано")
            QTimer.singleShot(2000, lambda: self.status_label.setText("Готов"))

    def _clean_logs(self) -> None:
        reply = QMessageBox.question(
            self, "Очистка логов",
            "Удалить все сообщения старше 14 дней?\nЭто действие нельзя отменить.",
            QMessageBox.Yes | QMessageBox.No,
        )
        if reply == QMessageBox.Yes:
            try:
                self.logger.clean_old_logs(14)
                self.reload()
                QMessageBox.information(self, "Успех", "Старые логи удалены")
            except Exception as exc:
                QMessageBox.critical(self, "Ошибка", f"Ошибка очистки: {exc}")

    def load_chat_history(self):
        """Load chat history from disk with thread-safety."""
        history_file = CHAT_HISTORY_PATH
        if os.path.exists(history_file):
            try:
                with open(history_file, 'r', encoding='utf-8') as f:
                    data = json.load(f)
                with self.chats_lock:
                    self.chats = data
            except (json.JSONDecodeError, OSError):
                with self.chats_lock:
                    self.chats = {}

    def save_chat_history(self):
        """Save chat history to disk with thread-safety."""
        history_file = CHAT_HISTORY_PATH
        with self.chats_lock:
            data = self.chats.copy()
        with open(history_file, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)

    def delete_current_chat(self):
        if not self.current_contact:
            QMessageBox.warning(self, "Ошибка", "Выберите диалог для удаления")
            return

        reply = QMessageBox.question(
            self, "Удаление диалога",
            f"Удалить диалог с {self.current_contact}? История переписки будет удалена.",
            QMessageBox.Yes | QMessageBox.No,
        )
        if reply == QMessageBox.Yes:
            contact = self.current_contact

            if contact in self.chats:
                del self.chats[contact]
                self.save_chat_history()

                conn = sqlite3.connect('logs/messages.db')
                cursor = conn.cursor()
                cursor.execute(
                    "DELETE FROM messages WHERE sender LIKE ? OR recipient LIKE ?",
                    (f'%{contact}%', f'%{contact}%'),
                )
                conn.commit()
                conn.close()

                self.current_contact = None
                self.chat_view.clear_header()
                self.chat_view.set_enabled_for_chat(False)
                self.profile_panel.hide_panel()
                self.refresh_chats_list()
                self.log_callback(f"Диалог с {contact} удален", "INFO")
                self._history_dirty = True

    # ---- protected: имя/поведение не менять, меняются только виджеты внутри ----

    def refresh_chats_list(self):
        entries = []
        for contact, messages in self.chats.items():
            last_msg = messages[-1]["message"][:60] if messages else ""
            last_time = messages[-1]["time"] if messages else ""
            # Время последней активности: полный timestamp (ts) у новых сообщений,
            # 0.0 — для старых диалогов без ts и пустых чатов (остаются внизу).
            last_ts = messages[-1].get("ts", 0.0) if messages else 0.0
            entries.append((
                last_ts,
                {
                    "jid": contact,
                    "name": contact,
                    "preview": last_msg,
                    "time": last_time,
                    "unread": self.get_unread_count(contact),
                },
            ))
        # Свежие диалоги — выше (сортировка стабильна: при равных ts сохраняется
        # порядок вставки в self.chats).
        entries.sort(key=lambda e: e[0], reverse=True)
        self.sidebar.set_chats([row for _, row in entries])

    def get_unread_count(self, contact):
        if contact not in self.chats:
            return 0
        return sum(1 for msg in self.chats[contact]
                   if msg.get('type') == 'received' and not msg.get('read', False))

    def refresh_chat_display(self):
        if not self.current_contact or self.current_contact not in self.chats:
            self.chat_view.set_messages([])
            return

        messages = self.chats[self.current_contact]
        self.chat_view.set_messages(messages)

        # Как и в исходной версии: открытый чат неявно помечает входящие read
        # (реальную displayed-квитанцию по XMPP шлёт mark_messages_as_read).
        changed = False
        for msg in messages:
            if msg["type"] == "received" and not msg.get("read", False):
                msg["read"] = True
                changed = True
        if changed:
            self.save_chat_history()

        self.refresh_chats_list()

    def send_chat_message(self):
        if not self.current_contact:
            QMessageBox.warning(self, "Ошибка", "Выберите чат")
            return

        if not self.xmpp_service or not self.xmpp_service.client.is_connected:
            QMessageBox.warning(self, "Ошибка", "Нет подключения к XMPP серверу")
            return

        message = self.chat_view.message_input.toPlainText().strip()
        if not message:
            return

        try:
            message = validate_message(message)
        except ValueError as exc:
            QMessageBox.warning(self, "Ошибка", str(exc))
            return

        try:
            msg_id = str(uuid.uuid4())

            if self.current_contact not in self.chats:
                self.chats[self.current_contact] = []

            self.chats[self.current_contact].append({
                'type': 'sent',
                'message': message,
                'time': datetime.now().strftime("%H:%M:%S"),
                'ts': time.time(),
                'status': 'sending',
                'msg_id': msg_id,
            })
            self.pending_messages[msg_id] = self.current_contact
            self.save_chat_history()
            self.refresh_chat_display()
            self.chat_view.clear_input()

            self.xmpp_service.client.queue_message(
                self.current_contact, message, msg_id=msg_id
            )
            self.log_callback(f"Сообщение поставлено в очередь: {self.current_contact}", "INFO")

        except Exception as e:
            self.update_message_status(msg_id, 'failed')
            QMessageBox.critical(self, "Ошибка", f"Не удалось отправить: {str(e)}")

    def _on_send_requested(self, _text: str) -> None:
        """ChatViewWidget сам не отправляет — просит XMPPGUI сделать это по имени
        send_chat_message (имя/поведение метода не меняется)."""
        self.send_chat_message()

    def update_message_status(self, msg_id, status):
        contact = self.pending_messages.get(msg_id)
        if contact and contact in self.chats:

            target_idx = None
            for i, msg in enumerate(self.chats[contact]):
                if msg.get('msg_id') == msg_id and msg['type'] == 'sent':
                    target_idx = i
                    break
            if target_idx is None:
                return
            changed = False

            if status == 'read':
                for msg in self.chats[contact][:target_idx + 1]:
                    if msg['type'] == 'sent':
                        current = msg.get('status', 'sending')
                        if current in ('sending', 'delivered'):
                            msg['status'] = 'read'
                            changed = True
            else:
                msg = self.chats[contact][target_idx]
                current = msg.get('status', 'sending')
                if status == 'delivered' and current in ('sending',):
                    msg['status'] = status
                    changed = True
                elif status == 'failed':
                    msg['status'] = status
                    changed = True
            if changed:
                self.save_chat_history()
                if self.current_contact == contact:
                    self.refresh_chat_display()

    def mark_messages_as_read(self, contact):
        """Отметить сообщения как прочитанные и отправить подтверждение"""
        if contact in self.chats:
            updated = False
            for msg in self.chats[contact]:
                if msg['type'] == 'received' and not msg.get('read', False):
                    msg['read'] = True
                    updated = True
            if updated:
                self.save_chat_history()
                self.refresh_chats_list()
                if self.current_contact == contact:
                    self.refresh_chat_display()

                try:
                    if (
                        self.xmpp_service
                        and self.xmpp_service.client
                        and self.xmpp_service.client.is_connected
                    ):
                        last_incoming_id = None
                        for msg in reversed(self.chats.get(contact, [])):
                            if msg.get('type') == 'received' and msg.get('msg_id'):
                                last_incoming_id = msg['msg_id']
                                break
                        if last_incoming_id:
                            self.xmpp_service.client.send_displayed_marker(
                                contact, last_incoming_id
                            )
                            self.log_callback(
                                f"\u2705 Отправлено подтверждение прочтения для {contact}", "INFO"
                            )
                except Exception as e:
                    self.log_callback(f"Ошибка отправки подтверждения: {str(e)}", "ERROR")

    # --- Публичные обработчики, вызываемые из потоков (только emit!) ---

    def on_delivery_received(self, msg_id):
        self.sig_delivery_received.emit(msg_id)

    def on_send_failed(self, msg_id):
        self.sig_send_failed.emit(msg_id)

    def on_receipt_received(self, msg_id):
        self.sig_receipt_received.emit(msg_id)

    def receive_message(self, from_jid, message, msg_id=None):
        self.sig_received_message.emit(from_jid, message, msg_id or "")

    def log_callback(self, message, level="INFO"):
        self.sig_log.emit(message, level)

    # --- Слоты главного потока ---

    @pyqtSlot(str)
    def _on_send_failed_safe(self, msg_id):
        self.logger.mark_failed(msg_id)
        self.update_message_status(msg_id, 'failed')
        self.log_callback(f"Не удалось отправить сообщение: {msg_id}", "ERROR")

    @pyqtSlot(str)
    def _on_delivery_received_safe(self, msg_id):
        self.logger.mark_delivered(msg_id)
        self.log_callback(f"\u2713 Доставлено: {msg_id}", "INFO")
        self.update_message_status(msg_id, 'delivered')

    @pyqtSlot(str)
    def _on_receipt_received_safe(self, msg_id):
        self.log_callback(
            f'DEBUG read: msg_id={msg_id} pending={list(self.pending_messages.keys())[:5]}', 'INFO'
        )
        self.logger.mark_read(msg_id)
        self.log_callback(f"\u2713\u2713 Прочитано: {msg_id}", "INFO")
        self.update_message_status(msg_id, 'read')

    @pyqtSlot(str, str, str)
    def _on_message_sent_safe(self, to_user, message, msg_id):
        """Слот главного потока: обновляет GUI после отправки через REST API."""
        self.refresh_chats_list()
        if self.current_contact == to_user:
            self.refresh_chat_display()
        self._history_dirty = True

    @pyqtSlot(str, str, str)
    def _process_received_message(self, from_jid, message, msg_id):
        try:
            if from_jid not in self.chats:
                self.chats[from_jid] = []

            if not msg_id:
                msg_id = str(int(datetime.now().timestamp() * 1000))
            self.chats[from_jid].append({
                'type': 'received',
                'message': message,
                'time': datetime.now().strftime("%H:%M:%S"),
                'ts': time.time(),
                'read': False,
                'msg_id': msg_id,
            })
            self.save_chat_history()

            self.log_callback(f"\U0001F4E9 Получено сообщение от {from_jid}: {message}", "INFO")

            self._history_dirty = True
            self.refresh_chats_list()

            if self.current_contact == from_jid:
                self._chat_dirty = True
                if msg_id and self.xmpp_service and self.xmpp_service.client and self.xmpp_service.client.is_connected:
                    self.xmpp_service.client.send_displayed_marker(from_jid, msg_id)
            else:
                self.status_label.setText(f"\U0001F4E9 Новое сообщение от {from_jid}")
                QTimer.singleShot(3000, lambda: self.status_label.setText("\U0001F7E2 Подключено"))
        except Exception as e:
            self.log_callback(f"Ошибка обработки сообщения: {str(e)}", "ERROR")

    # ================================================================== подключение / REST

    def connect_xmpp(self):
        # Решение 1 из docstring: логин/пароль читаются из self.config,
        # а не из виджета настроек (тот теперь не живёт постоянно).
        username = self.config.get("xmpp", {}).get("username", "").strip()
        password = self.config.get("xmpp", {}).get("password", "")

        if not username or not password:
            QMessageBox.warning(self, "Ошибка", "Введите логин и пароль в настройках")
            return

        if getattr(self, "_connect_worker", None) and self._connect_worker.isRunning():
            return

        self.status_label.setText("\u23F3 Подключение...")
        self.log_callback("Подключение к XMPP...", "INFO")

        self._connect_worker = XmppConnectWorker(
            self.config, self.log_callback, username, password, self.kafka_broker
        )
        self._connect_worker.finished.connect(self._on_xmpp_connect_finished)
        self._connect_worker.start()

    def _on_xmpp_connect_finished(self, success: bool, error: str):
        username = self.config.get("xmpp", {}).get("username", "").strip()

        if success and self._connect_worker.service:

class RateLimiter:
    """Simple rate limiter by IP address (requests per minute)."""
    def __init__(self, max_requests=100, window_seconds=60):
        self.max_requests = max_requests
        self.window_seconds = window_seconds
        self.requests = defaultdict(deque)

    def is_allowed(self, client_ip: str) -> bool:
        """Check if client can make a request."""
        now = time()
        requests = self.requests[client_ip]
        
        # Remove old requests outside the window
        while requests and requests[0] < now - self.window_seconds:
            requests.popleft()
        
        # Check limit
        if len(requests) >= self.max_requests:
            return False
        
        requests.append(now)
        return True

            "external_id": validate_external_id(raw_external_id),
        }

    def _call_handler(self, to_user, prepared, msg_id):
        """Для type=text — прежний вызов из 4 аргументов; для task/command добавляются type и payload."""
        if prepared["type"] == "text":
            return self.message_handler(to_user, prepared["message"], prepared["priority"], msg_id)
        return self.message_handler(
            to_user, prepared["message"], prepared["priority"], msg_id, prepared["type"], prepared["payload"]
        )

    def _find_duplicate(self, external_id):
        if not external_id or not self.message_logger:
            return None
        return self.message_logger.find_by_external_id(external_id)

    @staticmethod
    def _duplicate_body(row):
        import json as _json
        body = {
            "status": "success",
            "duplicate": True,
            "message_id": row["message_id"],
            "priority": row["priority"],
            "message_status": row["status"],
            "type": row.get("content_type") or "text",
            "to": row["recipient"],
            "message": row["message"],
        }
        if row.get("external_id"):
            body["external_id"] = row["external_id"]
        if row.get("payload"):
            body["payload"] = _json.loads(row["payload"])
        return body

    def _get_logger(self):
        """MessageLogger для чтения. Если не передан в конструктор, создаётся по пути из констант."""
        if self.message_logger is None:
            self.message_logger = MessageLogger(db_path=MESSAGES_DB_PATH)
        return self.message_logger

    def _record_queued(self, msg_id, to_user, message, priority, content_type="text",
                       payload=None, external_id=None):
        """Синхронно создаёт строку queued, чтобы GET /messages/{id} видел сообщение сразу.

        Возвращает "ok", "duplicate" (external_id уже занят — гонка двух одинаковых запросов)
        или "error"."""
        if not self.message_logger:
            return "ok"
        try:
            self.message_logger.log_message(
                "SENT", "api", to_user, message,
                message_id=msg_id, priority=priority, status="queued",
                external_id=external_id, content_type=content_type, payload=payload,
            )
            return "ok"
        except sqlite3.IntegrityError:
            return "duplicate"
        except Exception as exc:
            self._log(f"Не удалось записать queued {msg_id}: {exc}", "WARNING")
            return "error"

    def _mark_failed(self, msg_id):
        if not self.message_logger:
            return
        try:
            self.message_logger.mark_failed(msg_id)
        except Exception as exc:
            self._log(f"Не удалось пометить failed {msg_id}: {exc}", "WARNING")

    def _init_kafka(self):
        """Инициализация Kafka брокера."""
        try:
            kafka_config = self.config.get("kafka", {})
            bootstrap_servers = kafka_config.get("bootstrap_servers", "localhost:9092")
            
            self.kafka_broker = KafkaBroker(bootstrap_servers, self._log)
            if self.kafka_broker.connect():
                self._log("Kafka брокер инициализирован", "INFO")
            else:
                self._log("Ошибка подключения к Kafka, отключение", "ERROR")
                self.kafka_broker = None
        except Exception as exc:
            self._log(f"Ошибка инициализации Kafka: {exc}", "ERROR")
            self.kafka_broker = None

    def _publish_to_kafka(self, topic: str, message: dict):
        """Публикация сообщения в Kafka топик."""
        if not self.kafka_broker:
            return False
        try:
            return self.kafka_broker.publish(topic, message)
        except Exception as exc:
            self._log(f"Ошибка публикации в Kafka: {exc}", "ERROR")
            return False

    def _process_kafka_api_request(self, topic: str, message: dict):
        """Обработчик сообщений из Kafka для API-очереди."""
        if not self.message_handler:
            self._log("Message handler not configured for Kafka consumer", "ERROR")
            return

        try:
            to_user = message.get("to")
            text = message.get("message")
            if not to_user or not text:
                self._log(f"Неправильное сообщение из Kafka: {message}", "ERROR")
                return

            try:
                priority = normalize_priority(message.get("priority"))
            except ValueError:
                self._log(f"Неизвестный priority в Kafka-сообщении, используется normal: {message.get('priority')}", "WARNING")
                priority = "normal"
            try:
                prepared = self._prepare(
                    text, priority, message.get("type"), message.get("payload"), message.get("external_id")
                )
            except ValueError as exc:
                self._log(f"Некорректное Kafka-сообщение: {exc}", "ERROR")
                if message.get("message_id"):
                    self._mark_failed(message["message_id"])
                return
            msg_id = message.get("message_id")
            if not msg_id:
                # запись положил внешний продюсер напрямую в топик
                msg_id = str(uuid.uuid4())
                if self._record_queued(msg_id, to_user, prepared["message"], prepared["priority"],
                                       prepared["type"], prepared["payload"], prepared["external_id"]) == "duplicate":
                    self._log("Kafka: повторный external_id, сообщение пропущено", "WARNING")
                    return

            self._log(f"Обработка Kafka API-запроса для {to_user}", "INFO")
            success = self._call_handler(to_user, prepared, msg_id)
            if success:
                self._publish_message_event("SENT", to_user, text)
            else:
                self._mark_failed(msg_id)
                self._log(f"Kafka API message handler failed for {to_user}", "ERROR")
        except Exception as exc:
            self._log(f"Ошибка обработки Kafka сообщения: {exc}", "ERROR")

    def _publish_message_event(self, event_type: str, recipient: str, message: str):
        """Публикация события отправленного сообщения в Kafka."""
        kafka_config = self.config.get("kafka", {})
        if not kafka_config.get("enabled", False):
            return False

        topic = kafka_config.get("topics", {}).get("messages", "xmpp-messages")
        payload = {
            "type": event_type,
            "recipient": recipient,
            "message": message,
            "timestamp": datetime.now().isoformat(),
        }
        return self._publish_to_kafka(topic, payload)

    def _setup_kafka_consumers(self):
        """Запуск Kafka consumer для обработки API-очереди."""
        kafka_config = self.config.get("kafka", {})
        if not self.kafka_broker:
            return
        if not kafka_config.get("consume_api_requests", False):
            return
        if not self.message_handler:
            self._log("Message handler не задан — Kafka consumer не будет запущен", "WARNING")
            return

        topics = [kafka_config.get("topics", {}).get("api_requests", "xmpp-api-requests")]
        group = kafka_config.get("consumer_group", "xmpp-client")
        offset = kafka_config.get("auto_offset_reset", "latest")
        success = self.kafka_broker.subscribe(topics, group, self._process_kafka_api_request, auto_offset_reset=offset)
        if success:
            self._log(f"Kafka consumer запущен для топиков: {topics}", "INFO")

        @self._route(self.config['rest_api']['endpoint'], methods=allowed_methods)
        def send_message():
            """
            Отправить сообщение
            ---
            get:
              summary: Отправить сообщение (GET)
              parameters:
                - name: to
                  in: query
                  required: true
                  type: string
                - name: message
                  in: query
                  required: true
                  type: string
                - name: priority
                  in: query
                  type: string
                  enum: [low, normal, high, critical]
              responses:
                200:
                  description: Успешно
            post:
              summary: Отправить сообщение (POST)
              parameters:
                - name: body
                  in: body
                  required: true
                  schema:
                    type: object
                    properties:
                      to:
                        type: string
                      message:
                        type: string
                      priority:
                        type: string
                        enum: [low, normal, high, critical]
              responses:
                200:
                  description: Успешно
            """
            auth_error = self._check_api_key()
            if auth_error:
                return auth_error
            limited = self._rate_limited()
            if limited:
                return limited

            cfg = self._rest_cfg()
            try:
                if request.method == 'GET':
                    if not cfg.get('allow_get', False):
                        return self._err("method_not_allowed", "GET disabled. Use POST.", 405)
                    to_user = request.args.get('to')
                    message = request.args.get('message')
                    raw_priority = request.args.get('priority')
                    raw_type = raw_payload = None
                    raw_external_id = request.args.get('external_id')
                else:
                    data = request.get_json(silent=True)
                    if not data or not isinstance(data, dict):
                        return self._err("bad_request", "No JSON data provided", 400)

                    raw_priority = data.get('priority')
                    raw_type = data.get('type')
                    raw_payload = data.get('payload')
                    raw_external_id = data.get('external_id')
                    to_user = None
                    for field in _TO_FIELDS:
                        if field in data:
                            to_user = data[field]
                            break

                    message = None
                    for field in _TEXT_FIELDS:
                        if field in data:
                            message = str(data[field])
                            break

                    if not message and normalize_message_type_safe(raw_type) == "text":
                        if cfg.get('legacy_payload_as_message', False):
                            # устаревший режим: тело запроса целиком уходит как текст
                            payload_dump = {k: v for k, v in data.items() if k not in _SERVICE_FIELDS}
                            message = json.dumps(payload_dump, ensure_ascii=False)
                        else:
                            return self._err("bad_request", "Missing 'message' field", 400)

                if not to_user or (not message and normalize_message_type_safe(raw_type) == "text"):
                    return self._err("bad_request", "Missing 'to' or 'message' field", 400)

                try:
                    prepared = self._prepare(message, raw_priority, raw_type, raw_payload, raw_external_id)
                except ValueError as exc:
                    return self._err("bad_request", str(exc), 400)
                message, priority = prepared["message"], prepared["priority"]
                external_id = prepared["external_id"]

                existing = self._find_duplicate(external_id)
                if existing:
                    return jsonify(self._duplicate_body(existing)), 200

                msg_id = str(uuid.uuid4())
                recorded = self._record_queued(
                    msg_id, to_user, message, priority, prepared["type"], prepared["payload"], external_id
                )
                if recorded == "duplicate":
                    existing = self._find_duplicate(external_id)
                    if existing:
                        return jsonify(self._duplicate_body(existing)), 200

                def _extra(body):
                    body["type"] = prepared["type"]
                    if external_id:
                        body["external_id"] = external_id
                    if prepared["payload"]:
                        body["payload"] = prepared["payload"]
                    return body

                kafka_config = self.config.get("kafka", {})
                if kafka_config.get("enabled", False) and kafka_config.get("use_for_api_queue", False):
                    api_request = {
                        "to": to_user,
                        "message": message,
                        "message_id": msg_id,
                        "priority": priority,
                        "type": prepared["type"],
                        "payload": prepared["payload"],
                        "external_id": external_id,
                        "timestamp": datetime.now().isoformat(),
                        "api_key_used": bool(cfg.get("api_key"))
                    }
                    published = self._publish_to_kafka(
                        kafka_config.get("topics", {}).get("api_requests", "xmpp-api-requests"),
                        api_request,
                    )
                    if published:
                        self._log(f"API запрос отправлен в Kafka: {to_user}", "INFO")
                        return jsonify(_extra({
                            "status": "queued",
                            "message_id": msg_id,
                            "priority": priority,
                            "message_status": "queued",
                            "topic": kafka_config.get("topics", {}).get("api_requests", "xmpp-api-requests"),
                            "to": to_user,
                            "message": message,
                        })), 202
                    self._log("Не удалось отправить API запрос в Kafka, выполняем синхронную отправку", "WARNING")

                if not self.message_handler:
                    self._log("Message handler not configured", "ERROR")
                    self._mark_failed(msg_id)
                    return self._err("internal", "Message handler not configured", 500, message_id=msg_id)

                try:
                    send_time = datetime.now()
                    success = self._call_handler(to_user, prepared, msg_id)
                    if success and kafka_config.get("enabled", False) and kafka_config.get("publish_api_requests", True):
                        self._publish_message_event("SENT", to_user, message)
                except Exception as e:
                    self._log(f"Message handler crashed: {str(e)}", "ERROR")
                    self._mark_failed(msg_id)
                    return self._err("internal", f"Message handler error: {str(e)}", 500, message_id=msg_id)

                if success:
                    self._log(f"Сообщение отправлено {to_user}: {message[:50]}", "INFO")
                    return jsonify(_extra({
                        "status": "success",
                        "message_id": msg_id,
                        "priority": priority,
                        "message_status": "queued",
                        "to": to_user,
                        "message": message,
                        "send_time": send_time.isoformat()
                    })), 200
                else:
                    self._log(f"Ошибка отправки {to_user}", "ERROR")
                    self._mark_failed(msg_id)
                    return self._err("internal", "Failed to send message - XMPP client not connected or error",
                                     500, message_id=msg_id)

            except Exception as e:
                self._log(f"API error: {str(e)}", "ERROR")
                return self._err("internal", str(e), 500)

        @self._route('/stats', methods=['GET'])
        def get_stats():
            auth_error = self._check_api_key()
            if auth_error:
                return auth_error
            try:
                db_path = MESSAGES_DB_PATH
                if not os.path.exists(db_path):
                    return jsonify({"status": "success", "stats": {"total_messages": 0, "sent": 0, "received": 0}}), 200
                
                conn = sqlite3.connect(db_path)
                cursor = conn.cursor()
                cursor.execute("SELECT COUNT(*) FROM messages")
                total = cursor.fetchone()[0]
                cursor.execute("SELECT COUNT(*) FROM messages WHERE type = 'SENT'")
                sent = cursor.fetchone()[0]
                cursor.execute("SELECT COUNT(*) FROM messages WHERE type = 'RECEIVED'")
                received = cursor.fetchone()[0]
                conn.close()
                return jsonify({"status": "success", "stats": {"total_messages": total, "sent": sent, "received": received}}), 200
            except Exception as e:
                return self._err("internal", str(e), 500)

# Этап 1. Контракт priority / статусов (XMPP2 ↔ WakeUpMessengerW)

## 1. Приоритет (общий словарь)
`low` | `normal` | `high` | `critical`. Нет значения или пустое → `normal`.
Неизвестное значение: REST → 400, Android при приёме → `normal` (с записью в лог).

## 2. XMPP: расширение в `<message>`
```xml
<message to="user@domain" type="chat" id="6f1c...-uuid">
  <body>Текст (до 256 символов)</body>
  <request xmlns="urn:xmpp:receipts"/>
  <markable xmlns="urn:xmpp:chat-markers:0"/>
  <priority xmlns="urn:wakeup:msg:0" level="critical"/>
</message>
```
- `id` сообщения = `message_id` в БД сервера = `id` в Room на Android (сквозной ID).
- Формат ID: UUID4 (вместо `int(time()*1000)`), чтобы `/broadcast` не давал дублей.
- Нет расширения → `normal` (старые отправители не ломаются).

## 3. REST сервера
**POST /send_message** — тело: `to`, `message`, необязательный `priority`.
Ответ 200: `{"status":"success","message_id":"...","priority":"high","message_status":"sent","to":"...","send_time":"..."}`
(при Kafka-очереди: 202, `message_status":"queued"`, тот же `message_id`).

**POST /broadcast** — то же + `priority`; в `results[]` у каждого получателя свой `message_id`.

**GET /messages/{message_id}** — точечный статус:
```json
{"status":"success","message":{
  "message_id":"...","recipient":"user@domain","priority":"high",
  "status":"delivered","send_time":"...","delivery_time":"...","read_time":null}}
```
404 — ID неизвестен. Авторизация `X-API-Key`, как у остальных.

**Статусы:** `queued → sent → delivered → read`, ответвление `failed` (только до доставки).
Статус монотонный: `read` не откатывается в `delivered`.

**/get_messages** дополняется полями `message_id`, `priority`, `status`.

## 4. Android: приоритет → поведение (Android 10, API 29)
Действие команды не зависит от приоритета: `task` всегда будит WMS, `ping` всегда тихий.
Приоритет определяет только уведомление:

| priority | канал (новый ID) | поведение |
|---|---|---|
| low | `wakeup_msg_low`, IMPORTANCE_LOW | тихо, в шторке |
| normal | `wakeup_msg_normal`, IMPORTANCE_DEFAULT | звук |
| high | `wakeup_msg_high`, IMPORTANCE_HIGH | звук + вибрация + heads-up |
| critical | `wakeup_msg_critical`, IMPORTANCE_HIGH + fullScreenIntent | Activity поверх блокировки, экран включается; звук один раз, без кнопки подтверждения |

Каналы имеют новые ID, потому что важность уже созданных каналов менять нельзя.
На API 29 `USE_FULL_SCREEN_INTENT` — обычное разрешение (достаточно манифеста).

## 5. Доверенные отправители
Список приходит через REST (эндпоинт и поле уточняем на этапе 7). До получения списка
приоритет `critical` понижается до `high`, чтобы посторонний отправитель не поднимал full-screen.

"""
Модуль автообновления клиента через GitHub Releases.

На Windows исполняемый файл и загруженные библиотеки заблокированы, пока
процесс работает, поэтому обновление применяется в два шага:
  1. архив распаковывается во временную staging-папку;
  2. запускается отдельный bat-скрипт, который дожидается завершения процесса
     клиента, копирует файлы поверх старых и перезапускает клиент.

На POSIX-системах используется классическая схема распаковки + os.execv.
"""
import os
import shutil
import subprocess
import sys
import tempfile
import threading
import zipfile

import requests
from version import VERSION

GITHUB_REPO = "Ottiks17/XMPP2"
GITHUB_API_URL = f"https://api.github.com/repos/{GITHUB_REPO}/releases/latest"


def get_latest_release():
    """Получить информацию о последнем релизе с GitHub."""
    try:
        response = requests.get(GITHUB_API_URL, timeout=10)
        if response.status_code == 200:
            return response.json()
    except Exception:
        pass
    return None


def compare_versions(current, latest):
    """Сравнить версии. Возвращает True если latest новее."""
    try:
        current_parts = [int(x) for x in current.strip("v").split(".")]
        latest_parts = [int(x) for x in latest.strip("v").split(".")]
        return latest_parts > current_parts
    except Exception:
        return False


def download_update(url, dest_path, progress_callback=None):
    """Скачать файл обновления."""
    try:
        response = requests.get(url, stream=True, timeout=60)
        response.raise_for_status()
        total = int(response.headers.get("content-length", 0))
        downloaded = 0
        with open(dest_path, "wb") as f:
            for chunk in response.iter_content(chunk_size=8192):
                if not chunk:
                    continue
                f.write(chunk)
                downloaded += len(chunk)
                if progress_callback and total:
                    progress_callback(int(downloaded / total * 100))
        return True
    except Exception:
        return False


def _application_dir() -> str:
    """Директория установки приложения (или откуда запущен скрипт)."""
    if getattr(sys, "frozen", False):
        return os.path.dirname(os.path.abspath(sys.executable))
    return os.path.dirname(os.path.abspath(__file__))


def install_update(zip_path):
    """Распаковать обновление и перезапустить клиент.

    На Windows применяется двухшаговая схема со staging-папкой и bat-скриптом,
    потому что запущенный исполняемый файл нельзя перезаписать напрямую.
    """
    try:
        app_dir = _application_dir()
        if sys.platform == "win32":
            _install_windows(zip_path, app_dir)
        else:
            with zipfile.ZipFile(zip_path, "r") as z:
                z.extractall(app_dir)
            os.remove(zip_path)
            os.execv(sys.executable, [sys.executable] + sys.argv)
        return True
    except Exception:
        return False


def _install_windows(zip_path: str, app_dir: str) -> None:
    """Windows: распаковка в staging + запуск bat-скрипта замены и перезапуска."""
    staging = tempfile.mkdtemp(prefix="xmpp_update_")
    script_path = os.path.join(
        tempfile.gettempdir(), f"xmpp_update_{os.getpid()}.bat"
    )
    try:
        with zipfile.ZipFile(zip_path, "r") as z:
            z.extractall(staging)
        os.remove(zip_path)

        _write_update_script(
            script_path,
            staging=staging,
            app_dir=app_dir,
            executable=sys.executable,
            pid=os.getpid(),
        )

        # Скрипт запускается отдельно от процесса клиента (detached), поэтому
        # он не будет убит вместе с клиентом и сможет его перезапустить.
        subprocess.Popen(
            ["cmd.exe", "/c", script_path],
            creationflags=_detached_flags(),
            close_fds=True,
        )
    except Exception:
        # staging и скрипт не нужны, если запустить обновление не удалось.
        shutil.rmtree(staging, ignore_errors=True)
        try:
            os.remove(script_path)
        except OSError:
            pass
        raise


def _detached_flags() -> int:
    """Флаги CreateProcess, чтобы bat-скрипт пережил завершение клиента."""
    flags = 0
    for name in ("CREATE_NEW_PROCESS_GROUP", "DETACHED_PROCESS", "CREATE_NO_WINDOW"):
        flags |= getattr(subprocess, name, 0)
    return flags


def _write_update_script(script_path, *, staging, app_dir, executable, pid):
    """Пишет bat-скрипт, который после завершения клиента применяет обновление.

    Пути встраиваются в текст скрипта напрямую, чтобы не зависеть от правил
    квотирования аргументов cmd.exe. Внутри двойных кавычек спецсимволы
    &|<>^ литеральны, поэтому экранируется только '%' (в bat это метасимвол).
    """
    def _q(value):
        return '"' + str(value).replace("%", "%%") + '"'

    staging_glob = _q(os.path.join(staging, "*"))
    app_dir_dst = _q(app_dir + os.sep)
    exe = _q(executable)
    pid_s = str(pid)

    lines = [
        "@echo off",
        "setlocal",
        "rem Ждём завершения процесса клиента (PID %s)." % pid_s,
        ":waitloop",
        'tasklist /FI "PID eq %s" 2>NUL | find "%s" >NUL' % (pid_s, pid_s),
        "if not errorlevel 1 (",
        "  ping -n 2 127.0.0.1 >NUL",
        "  goto waitloop",
        ")",
        "",
        "rem Копируем файлы обновления поверх установленных.",
        "xcopy /E /Y /I %s %s >NUL" % (staging_glob, app_dir_dst),
        "",
        "rem Удаляем staging-папку.",
        "rmdir /S /Q %s" % _q(staging),
        "",
        "rem Перезапускаем клиент.",
        "start \"\" %s" % exe,
        "",
        "rem Удаляем сам скрипт.",
        'del "%~f0" >NUL 2>&1',
        "endlocal",
    ]
    with open(script_path, "w", encoding="utf-8", newline="") as f:
        f.write("\r\n".join(lines) + "\r\n")


def check_for_updates(callback):

    Проверить обновления в фоновом потоке.
    callback(has_update, latest_version, download_url) вызывается когда проверка завершена.
    """
    def _check():
        release = get_latest_release()
        if not release:
            callback(False, None, None)
            return
        latest_version = release.get("tag_name", "").strip("v")
        if not compare_versions(VERSION, latest_version):
            callback(False, None, None)
            return
        # Найти zip файл в assets

        for asset in release.get("assets", []):
            if asset["name"].endswith(".zip"):
                download_url = asset["browser_download_url"]

def deep_merge(base: dict, override: dict) -> dict:
    result = deepcopy(base)

def validate_device_id(value) -> str:
    text = str(value or "").strip()
    if not text or len(text) > _DEVICE_ID_MAX or not text.isprintable():
        raise ValueError(f"deviceId: от 1 до {_DEVICE_ID_MAX} печатных символов")
    return text


def _load_key(db_path: str) -> bytes:
    env = os.getenv("DEVICE_REGISTRY_KEY")
    if env:
        return env.encode("ascii")
    key_path = os.path.join(os.path.dirname(db_path) or ".", "device_registry.key")
    if os.path.exists(key_path):
        with open(key_path, "rb") as handle:
            return handle.read().strip()
    os.makedirs(os.path.dirname(key_path) or ".", exist_ok=True)
    key = Fernet.generate_key()
    fd = os.open(key_path, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
    with os.fdopen(fd, "wb") as handle:
        handle.write(key)
    return key


def _hash_token(token: str) -> str:
    return hashlib.sha256(token.encode("utf-8")).hexdigest()

"""Kafka broker для публикации сообщений и очередирования запросов."""

from __future__ import annotations

import json
import logging
from typing import Any, Callable, Optional
from threading import Thread, Event

from kafka import KafkaProducer, KafkaConsumer
from kafka.errors import KafkaError

logger = logging.getLogger(__name__)


class KafkaBroker:
    """Управление публикацией и потреблением сообщений Kafka."""

    def __init__(
        self,
        bootstrap_servers: str | list[str],
        log_callback: Optional[Callable[[str, str], None]] = None,
    ):
        self.bootstrap_servers = bootstrap_servers
        self.log_callback = log_callback
        self.producer: Optional[KafkaProducer] = None
        self.consumers: dict[str, KafkaConsumer] = {}
        self.consumer_threads: dict[str, Thread] = {}
        self.stop_consumers = Event()

    def _log(self, message: str, level: str = "INFO"):
        """Логирование с callback."""
        if self.log_callback:
            self.log_callback(f"[Kafka] {message}", level)
        else:
            logger.log(getattr(logging, level), message)

    def connect(self) -> bool:
        """Подключение к Kafka и инициализация producer."""
        try:
            self.producer = KafkaProducer(
                bootstrap_servers=self.bootstrap_servers,
                value_serializer=lambda v: json.dumps(v, ensure_ascii=False).encode(
                    "utf-8"
                ),
                acks="all",  # Гарантия доставки
                retries=3,
                request_timeout_ms=10000,
            )
            self._log("Успешно подключено к Kafka", "INFO")
            return True
        except Exception as exc:
            self._log(f"Ошибка подключения к Kafka: {exc}", "ERROR")
            return False

    def publish(
        self, topic: str, message: dict[str, Any], key: Optional[str] = None
    ) -> bool:
        """
        Публикация сообщения в топик.

        Args:
            topic: Название топика
            message: Сообщение (будет сохранено как JSON)
            key: Ключ сообщения (опционально)

        Returns:
            True если успешно, False иначе
        """
        if not self.producer:
            self._log("Producer не инициализирован", "ERROR")
            return False

        try:
            future = self.producer.send(
                topic, value=message, key=key.encode() if key else None
            )
            # Блокирующая отправка с timeout
            future.get(timeout=5)
            self._log(f"Опубликовано сообщение в {topic}", "DEBUG")
            return True
        except KafkaError as exc:
            self._log(f"Ошибка публикации в {topic}: {exc}", "ERROR")
            return False
        except Exception as exc:
            self._log(f"Неожиданная ошибка при публикации: {exc}", "ERROR")
            return False

    def subscribe(
        self,
        topics: list[str],
        consumer_group: str,
        handler: Callable[[str, dict[str, Any]], None],
        auto_offset_reset: str = "latest",
    ) -> bool:
        """
        Подписка на топики с обработчиком сообщений.

        Args:
            topics: Список топиков для подписки
            consumer_group: Группа потребителей
            handler: Функция-обработчик (topic, message) -> None
            auto_offset_reset: 'earliest' или 'latest'

        Returns:
            True если успешно, False иначе
        """
        try:
            consumer_key = f"{consumer_group}:{','.join(topics)}"

            if consumer_key in self.consumers:
                self._log(f"Уже подписаны на {topics}", "WARNING")
                return False

            consumer = KafkaConsumer(
                *topics,
                bootstrap_servers=self.bootstrap_servers,
                group_id=consumer_group,
                auto_offset_reset=auto_offset_reset,
                enable_auto_commit=True,
                value_deserializer=lambda m: json.loads(m.decode("utf-8")),
                session_timeout_ms=6000,
                request_timeout_ms=10000,
            )

            self.consumers[consumer_key] = consumer

            # Запуск потока для обработки сообщений
            thread = Thread(
                target=self._consume_messages,
                args=(consumer_key, consumer, handler),
                daemon=True,
            )
            thread.start()
            self.consumer_threads[consumer_key] = thread

            self._log(f"Подписаны на {topics} в группе {consumer_group}", "INFO")
            return True

        except Exception as exc:
            self._log(f"Ошибка подписки: {exc}", "ERROR")
            return False

    def _consume_messages(
        self, consumer_key: str, consumer: KafkaConsumer, handler: Callable
    ):
        """Поток для потребления сообщений с retry logic."""
        import time
        try:
            while not self.stop_consumers.is_set():
                for message in consumer:
                    if self.stop_consumers.is_set():
                        break
                    
                    # Retry logic: до 3 попыток обработки
                    max_retries = 3
                    for attempt in range(max_retries):
                        try:
                            handler(message.topic, message.value)
                            break  # Success, exit retry loop
                        except Exception as exc:
                            if attempt < max_retries - 1:
                                self._log(
                                    f"Ошибка обработки сообщения (попытка {attempt + 1}/{max_retries}): {exc}",
                                    "WARNING",
                                )
                                # Exponential backoff
                                time.sleep(2 ** attempt)
                            else:
                                self._log(
                                    f"Исчерпаны попытки обработки сообщения из {message.topic}: {exc}",
                                    "ERROR",
                                )
        except Exception as exc:
            self._log(f"Ошибка в consumer потоке {consumer_key}: {exc}", "ERROR")
        finally:
            consumer.close()
            self.consumers.pop(consumer_key, None)

    def unsubscribe(self, topics: list[str], consumer_group: str) -> bool:
        """Отписка от топиков."""
        consumer_key = f"{consumer_group}:{','.join(topics)}"
        if consumer_key in self.consumers:
            self.consumers[consumer_key].close()
            self.consumers.pop(consumer_key, None)
            return True
        return False

    def disconnect(self):
        """Отключение от Kafka."""
        self.stop_consumers.set()

        # Закрыть все consumers
        for consumer in self.consumers.values():
            consumer.close()
        self.consumers.clear()

        # Дождаться завершения потоков
        for thread in self.consumer_threads.values():
            thread.join(timeout=2)
        self.consumer_threads.clear()

        # Закрыть producer
        if self.producer:
            self.producer.close()
            self.producer = None

        self._log("Отключено от Kafka", "INFO")

    def __del__(self):
        """Очистка при удалении объекта."""
        try:
            self.disconnect()
        except Exception:
            pass

def _backup(db_path: str, old_version: int) -> str:
    target = f"{db_path}.bak-v{old_version}"
    if os.path.exists(target):
        stamp = datetime.now().strftime("%Y%m%d%H%M%S")
        target = f"{db_path}.bak-v{old_version}-{stamp}"
    with closing(sqlite3.connect(db_path)) as src, closing(sqlite3.connect(target)) as dst:
        src.backup(dst)
    return target


def migrate(db_path: str) -> int:
    """Приводит БД к актуальной схеме. Возвращает итоговую версию.

    Перед миграцией существующей БД делается копия <db>.bak-v<старая версия>.
    Каждая миграция выполняется в своей транзакции вместе с обновлением user_version:
    при ошибке БД остаётся на предыдущей версии.
    """
    os.makedirs(os.path.dirname(db_path) or ".", exist_ok=True)
    existed = os.path.exists(db_path) and os.path.getsize(db_path) > 0
    with closing(sqlite3.connect(db_path, isolation_level=None)) as conn:
        current = conn.execute("PRAGMA user_version").fetchone()[0]
        if current > SCHEMA_VERSION:
            raise RuntimeError(
                f"БД версии {current} новее приложения (поддерживается {SCHEMA_VERSION})"
            )
        pending = [(v, fn) for v, fn in MIGRATIONS if v > current]
        if not pending:
            return current
        if existed and current > 0:
            _backup(db_path, current)
        elif existed:
            # user_version=0, но файл не пустой: БД от старой версии приложения
            _backup(db_path, 0)
        for version, fn in pending:
            conn.execute("BEGIN IMMEDIATE")
            try:
                fn(conn)
                conn.execute(f"PRAGMA user_version = {version}")
                conn.execute("COMMIT")
            except Exception:
                conn.execute("ROLLBACK")
                raise
        conn.execute("PRAGMA journal_mode=WAL")
        return SCHEMA_VERSION

        self.resource = "".join(
            random.choices(string.ascii_lowercase + string.digits, k=8)
        )
        self._send_raw(
            f'<stream:stream to="{self.server}" xmlns="jabber:client" '
            f'xmlns:stream="http://etherx.jabber.org/streams" version="1.0">'

            f'<iq type="set" id="bind_1"><bind xmlns="urn:ietf:params:xml:ns:xmpp-bind">'
            f"<resource>{self.resource}</resource></bind></iq>"

        time.sleep(0.5)

        response = self._receive_data()
        jid_match = re.search(r'jid="([^"]+)"', response)

        self._log(f"Подключено: {self.full_jid}", "INFO")

        """Send XMPP message with delivery receipts.
        
        Args:
            to (str): Recipient JID
            message (str): Message text (max 256 chars)
            msg_id (str, optional): Message ID. Defaults to uuid4.
            priority (str, optional): low/normal/high/critical. Defaults to normal.
            msg_type (str): text/task/command (контракт v1.0). Для task/command добавляется
                элемент <task>/<command> в пространстве urn:wakeup:msg:0.

            str: Message ID if successful, None otherwise.

            if not self.reconnect():
                return None

        try:
            if len(message) > 256:
                raise ValueError("Message exceeds 256 characters")
            escaped = _escape_xml(message)
            priority = normalize_priority(priority)

                msg_id = str(uuid.uuid4())

                f'<message to="{_escape_xml(to)}" type="chat" id="{_escape_xml(msg_id)}">'
                f"<body>{escaped}</body>"
                f'<request xmlns="urn:xmpp:receipts"/>'
                f'<markable xmlns="urn:xmpp:chat-markers:0"/>'
                f'<priority xmlns="{PRIORITY_NS}" level="{priority}"/>'
                f"{build_payload_xml(msg_type, payload)}"
                f"</message>"
            )
            self._send_raw(msg_xml)
            self._log_message(

                sender=self.full_jid or self.jid,

                message=message,

    def _read_loop(self):

        while self.running and self.is_connected:
            try:

                    time.sleep(0.1)
                    continue
                buffer += data
                raw_str = data if isinstance(data, str) else data.decode('utf-8', errors='ignore')
                if 'displayed' in raw_str or ('received' in raw_str and 'urn:xmpp:receipts' in raw_str):
                    self._log(f"RAW_MARKER: {raw_str[:800]}", "INFO")

    def _process_incoming_message(self, msg_xml):
        from_m = re.search(r'from="([^"]+)"', msg_xml)
        body_m = re.search(r"<body>(.*?)</body>", msg_xml)
        id_m = re.search(r'id="([^"]+)"', msg_xml)
        # Handle <received> receipt inside <message> (XEP-0184)
        if from_m and not body_m:
            # Check for delivery receipt
            recv_m = re.search(r'<received[^>]*/>', msg_xml)
            if not recv_m:
                recv_m = re.search(r'<received[^>]*></received>', msg_xml)
            if recv_m:
                recv_id_m = re.search(r'id="([^"]+)"', recv_m.group(0))
                if recv_id_m and self.on_delivery_received:
                    self.on_delivery_received(recv_id_m.group(1))
            # Check for displayed marker
            disp_m = re.search(r'<displayed[^>]*/>', msg_xml)
            if not disp_m:
                disp_m = re.search(r'<displayed[^>]*></displayed>', msg_xml)
            if disp_m:
                disp_id_m = re.search(r'id="([^"]+)"', disp_m.group(0))
                if disp_id_m and self.on_read_received:
                    self.on_read_received(disp_id_m.group(1))
            return

        from_jid = from_m.group(1).split("/")[0]
        body = body_m.group(1)
        body = (
            body.replace("&lt;", "<")
            .replace("&gt;", ">")
            .replace("&quot;", '"')
            .replace("&amp;", "&")
        )
        incoming_id = id_m.group(1) if id_m else ""

        self._log_message(
            type="RECEIVED",
            sender=from_jid,
            recipient=self.jid,
            message=body,
            message_id=incoming_id,
            delivery_time=datetime.now(),
        )

        # Публикация входящего сообщения в Kafka
        if self.kafka_publisher:
            try:
                self.kafka_publisher(
                    "RECEIVED",
                    from_jid,
                    self.jid,
                    body
                )
            except Exception as exc:
                self._log(f"Kafka publisher error: {exc}", "ERROR")

        if incoming_id:
            self._send_raw(
                f'<message to="{_escape_xml(from_jid)}" type="chat">'
                f'<received xmlns="urn:xmpp:receipts" id="{_escape_xml(incoming_id)}"/>'
                f"</message>"
            )

        if self.on_message_received:
            self.on_message_received(from_jid, body, incoming_id or None)

    def _process_delivery(self, xml_chunk):
        id_m = re.search(r'id="([^"]+)"', xml_chunk)
        if id_m and self.on_delivery_received:
            self.on_delivery_received(id_m.group(1))

    def _process_read(self, xml_chunk):
        id_m = re.search(r'id="([^"]+)"', xml_chunk)
        if id_m and self.on_read_received:
            self.on_read_received(id_m.group(1))

    def _log(self, message, level="INFO"):
        if self.log_callback:
            self.log_callback(message, level)

    def _log_message(self, **fields):
        payload = {
            "type": fields.get("type"),
            "sender": fields.get("sender"),
            "recipient": fields.get("recipient"),
            "message": fields.get("message"),
            "message_id": fields.get("message_id"),
            "priority": fields.get("priority"),
            "send_time": fields["send_time"].isoformat()
            if fields.get("send_time")
            else None,
            "delivery_time": fields["delivery_time"].isoformat()
            if fields.get("delivery_time")
            else None,
            "read_time": None,
            "timestamp": datetime.now().isoformat(),
        }
        if self.log_callback:
            self.log_callback(json.dumps(payload, ensure_ascii=False), "MESSAGE")

    def disconnect(self):
        self.running = False
        self.is_connected = False
        if self.socket:
            try:
                self.socket.close()
            except OSError:
                pass
        self._log("Отключено", "INFO")

    def connect(self, username: str, password: str) -> bool:
        try:
            xmpp_cfg = self.config.get("xmpp", {})
            server = xmpp_cfg.get("server", "")
            if "@" in username:
                jid = username
            else:
                jid = f"{username}@{server}"

            env_password = password or xmpp_cfg.get("password") or ""
            use_slixmpp = bool(xmpp_cfg.get("use_slixmpp", False))

            # Создаем callback для публикации в Kafka
            kafka_publisher = None
            if self.kafka_broker and self.config.get("kafka", {}).get("publish_all_messages", False):
                kafka_publisher = self._create_kafka_publisher()

            if use_slixmpp and SlixmppClient is not None:
                self.client = SlixmppClient(
                    jid,
                    env_password,
                    server,
                    int(xmpp_cfg.get("port", 5222)),
                    bool(xmpp_cfg.get("use_tls", True)),
                    bool(xmpp_cfg.get("verify_tls", True)),
                    self.log_callback,
                    kafka_publisher=kafka_publisher,
                )
            else:
                self.client = SimpleXMPPClient(
                    jid,
                    env_password,
                    server,
                    int(xmpp_cfg.get("port", 5222)),
                    self.log_callback,
                    use_tls=bool(xmpp_cfg.get("use_tls", True)),
                    verify_tls=bool(xmpp_cfg.get("verify_tls", True)),
                    kafka_publisher=kafka_publisher,
                )

            return self.client.connect()
        except Exception as exc:
            if self.log_callback:
                self.log_callback(f"Connection failed: {exc}", "ERROR")
            return False

    def _create_kafka_publisher(self):
        """Создает callback для публикации сообщений в Kafka."""
        def publish_to_kafka(msg_type: str, sender: str, recipient: str, message: str):
            if not self.kafka_broker:
                return
            try:
                kafka_config = self.config.get("kafka", {})
                topic = kafka_config.get("topics", {}).get("messages", "xmpp-messages")
                
                msg_data = {
                    "type": msg_type,
                    "sender": sender,
                    "recipient": recipient,
                    "message": message,
                    "timestamp": None,  # Заполнится в native.py
                }
                self.kafka_broker.publish(topic, msg_data)
            except Exception as exc:
                if self.log_callback:
                    self.log_callback(f"Kafka publish error: {exc}", "ERROR")
        
        return publish_to_kafka

    def send_message(
        self,
        to_username: str,
        message: str,

        priority: Optional[str] = None,

        domain = self.config["xmpp"]["server"]

        if msg_type != "text" and self.log_callback:

        domain = self.config["xmpp"]["server"]
        to_jid = validate_jid(to_username, domain)
        return self.client.send_subscription_request(to_jid)

    def disconnect(self) -> None:
        if self.client:
            self.client.disconnect()
