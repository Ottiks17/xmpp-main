# Патч xmpp-main: контракт v1.0 (ТЗ-1, ТЗ-6, серверная часть ТЗ-7…10)

Распаковать и скопировать поверх проекта (папки сольются, пути совпадают). Удалять ничего не нужно.

1. `pip install -r requirements.txt` — добавилась зависимость `cryptography`.
2. Добавить в `.gitignore`: `logs/device_registry.key` (ключ шифрования паролей реестра терминалов).
3. Описание контракта — `contract_v1.md`; список изменений — `tools/CHANGELOG.md`.

Что изменилось в поведении (старые клиенты могут это заметить):
- запрос без текста даёт 400 (раньше тело запроса уходило в чат как JSON); старое поведение включается
  `rest_api.legacy_payload_as_message: true`;
- ключ API в `?api_key=` больше не принимается; включается `rest_api.allow_api_key_query: true`;
- ошибки теперь в формате `{"error": {"code": "...", "message": "..."}}` (раньше `{"error": "..."}`);
- `/broadcast` ограничен по частоте запросов и по длине списка (200).

БД мигрирует автоматически до версии 3 (перед этим создаётся копия `<db>.bak-v<версия>`).
